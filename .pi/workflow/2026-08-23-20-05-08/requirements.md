# 要件定義: `src/pages/posts/[id].astro` へのヘッダー追加

## 目的
`src/pages/posts/[id].astro`（個別記事ページ）に、最小構成のヘッダーを追加する。

## 機能要件
1. **対象ファイル**: `src/pages/posts/[id].astro`
2. **ヘッダーの構成要素**:
   - サイト名（ホームへのリンク）
   - カテゴリー一覧
3. **デザイン / スタイル**:
   - デザイン・CSSスタイルは適用せず、純粋なHTMLタグ（要素）のみとする。
4. **スコープ**:
   - 今回は特定ページ（`[id].astro`）専用の実装とする（共通コンポーネント化はスコープ外）。

## スコープ外
- CSSスタイリング（Tailwind CSSやカスタムCSSの適用）
- 共通レイアウトコンポーネント（Layout.astroなど）への抽出・共通化
- 高度な検索機能やお問い合わせフォームなどの追加要素
